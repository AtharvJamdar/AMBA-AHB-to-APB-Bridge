# Design-and-Verification-of-AMBA-AHB-to-APB-Bridge-with-CDC-using-UVM-
Designed and verified an RTL AMBA AHB-to-APB bridge with asynchronous clock-domain crossing using an async FIFO and handshake-based synchronization. Developed a reusable UVM testbench with CRV, SVA, functional coverage, and regression testing for protocol compliance and read/write transactions.
